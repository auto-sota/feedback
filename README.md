# Auto Sota feedback

Tell the team behind [autosota.com](https://autosota.com), the free car parts catalog, what is missing or wrong. We read every issue.

| | |
|---|---|
| **A car, brand or catalog is missing** | [Request it](https://github.com/auto-sota/feedback/issues/new?template=missing.yml) |
| **Something in the catalog is wrong** | [Report it](https://github.com/auto-sota/feedback/issues/new?template=wrong-data.yml) |
| **You have an idea** | [Suggest a feature](https://github.com/auto-sota/feedback/issues/new?template=idea.yml) |

Before you post, [search the open issues](https://github.com/auto-sota/feedback/issues). If someone already asked for the same thing, add a 👍 to it. We sort by 👍 when we choose what to add next.

Please do not post a full VIN or anything personal. The first 11 characters of a VIN are enough to identify the car.

What we have added so far: [updates](https://github.com/auto-sota/auto-sota/blob/main/UPDATES.md).
